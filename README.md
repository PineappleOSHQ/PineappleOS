# Pineapples OS

Pineapples is a lightweight, simulated operating system designed to execute core mobile tasks efficiently. Developed using block-based programming in Scratch and optimized via the TurboWarp engine, the project replicates essential smartphone functions within a highly responsive environment.

---

## Features

* **Voice Calling:** A functional interface to dial and contact preset profiles.
* **Camera Application:** Capture and view local images within the simulator.
* **Application Downloader:** A simulated storefront to browse, install, and run auxiliary modules.
* **High-Performance Architecture:** Optimized through TurboWarp compilation to ensure stable frame rates and minimal system overhead compared to standard Scratch deployments.

---

## Execution and Modification

Pineapples OS can be launched instantly as a web application or imported for custom development.

### Web Deployment (Instant Play)
1. Open the included `index.html` (or equivalent HTML build file) in any modern web browser.
2. The operating system will boot automatically within the standalone player interface.

### Source Customization
Because the project is built on open standards, you are free to modify the source code, user interface, or application logic in any way you see fit. 

1. Download the source `.sb3` file from this repository.
2. Navigate to [TurboWarp](https://turbowarp.org) or the standard Scratch editor.
3. Select `File` > `Load from your computer` and open the `.sb3` file.
4. Modify the block scripts, sprites, or variables as needed, then export your updated version.

## Technical Specifications

* **Development Environment:** Scratch 3.0
* **Compiler / Runtime Engine:** TurboWarp (JavaScript compiler extension for Scratch)
* **Distribution Formats:** Standalone HTML, Scratch project file (`.sb3`)
